# 响应式设计师作品集

这是一个面向桌面端与手机端的单页设计师作品集。页面采用深色沉浸式视觉，包括全屏首屏、个人简介、分类作品网格、项目预览灯箱与联系区。

## 本地运行

Windows 用户可直接双击项目根目录中的：

```text
打开本地编辑器.cmd
```

启动器会在后台运行本地服务，确认页面可访问后自动打开：

```text
http://localhost:3000/editor
```

也可以手动运行：

```powershell
pnpm.cmd install
pnpm.cmd dev
```

生产构建与预览：

```powershell
pnpm.cmd build
pnpm.cmd start
```

## 内容维护

打开以下地址可使用本地可视化编辑器：

```text
/editor
```

编辑器支持：

- 首页、个人介绍、经历、数据、联系信息和主题颜色修改
- 首页大标题、区块标题、正文和作品标题的桌面/手机字号、字间距与行距调整
- 作品筛选导航支持改名、新增、删除、隐藏、排序，并可组合关联多个作品分组
- 每个作品分组都可以新增或减少作品，并修改文案、图片、强调色与显示状态
- 每个作品支持最多 12 张内容图，可批量上传、排序和删除；第 1 张自动作为网站封面
- 长封面在电脑端会从顶部开始，鼠标悬停后用 0.1 秒滚动到底部；短图、手机端和减少动态效果模式保持静止
- 桌面端与手机端实时预览
- 上传时自动保留原图，并生成封面 WebP 与高清详情 WebP
- 配置自动保存、立即保存、导入、导出、旧浏览器内容迁移与恢复默认

编辑结果会直接保存到项目配置文件，图片主库位于：

```text
E:\本地编辑器存图
├─ 原图
├─ 网页图
├─ 回收站
└─ asset-index.json
```

图片不再保存到浏览器 `localStorage`，因此没有原来的 4MB 总容量限制。单张源图保留 100MB 安全上限；配置只记录资源地址。编辑器右下角会显示自动保存状态，侧栏可执行“立即保存”和未使用图片清理。

网站正式配置位于：

```text
data/portfolio-config.json
```

`data/portfolio.js` 仍提供首次运行时的默认文案和占位内容。旧版 `localhost:3000` 浏览器中若仍有历史配置，可在编辑器内执行一次迁移；迁移成功前不会自动删除旧数据。

## 发布资源

生产构建会自动：

1. 从 `E:\本地编辑器存图\网页图` 同步当前配置引用的文件到 `public/assets/portfolio/`。
2. 拒绝 Base64 图片、E 盘绝对路径和缺失资源。
3. 统计发布图片体积，超过 200MB 时给出警告。
4. 构建可部署的 Sites 产物。

可单独运行：

```powershell
pnpm.cmd run assets:prepare
pnpm.cmd build
```

E 盘中的原图、资源索引和回收站不会进入发布包。线上 `/editor` 会跳回首页，只有本机开发服务允许编辑和写入文件。

## 页面结构

- 固定胶囊导航

- 分类筛选与项目灯箱
- 联系方式
