# 响应式设计师作品集

这是一个面向桌面端与手机端的单页设计师作品集。页面采用深色沉浸式视觉，包括全屏首屏、个人简介、分类作品网格、项目预览灯箱与联系区。

## 本地运行

Windows 用户可直接双击项目根目录中的：

```text
打开本地编辑器.cmd
```

启动器会在后台运行本地服务，确认页面可访问后自动打开：

```text
http://localhost:3000/editor
```

也可以手动运行：

```powershell
pnpm.cmd install
pnpm.cmd dev
```

生产构建与预览：

```powershell
pnpm.cmd build
pnpm.cmd start
```

## 内容维护

打开以下地址可使用本地可视化编辑器：

```text
/editor
```

编辑器支持：

- 首页、个人介绍、经历、数据、联系信息和主题颜色修改
- 首页大标题、区块标题、正文和作品标题的桌面/手机字号、字间距与行距调整
- 18 个固定作品槽位的文案、封面、强调色与显示状态修改
- 详情页作品可分别上传“列表封面”和“完整详情长图”
- 桌面端与手机端实时预览
- 普通图片自动压缩；详情长图按完整比例优化，不裁切、不按最长边压扁
- 配置导入、导出与恢复默认

编辑结果保存在当前域名和浏览器的 `localStorage` 中，不会自动改写源码或发布到其他设备。单张本地图片最多约 1.5MB，总配置需控制在 4MB 以内；有多张高清详情长图时，建议把图片放入 `public/assets/` 或图床，再填写图片地址。

源码中的默认内容集中在：

```text
data/portfolio.js
```

当前默认作品封面和人物图为可直接运行的原创 CSS 概念占位视觉，不包含参考网站的原始图片或视频。需要把编辑结果变成所有访客都能看到的正式默认内容时：

1. 在编辑器中导出 JSON 配置。
2. 将图片放入 `public/assets/`，避免长期使用较大的 Base64 图片。
3. 把确认后的配置同步回 `data/portfolio.js` 并重新部署。

## 页面结构

- 固定胶囊导航
- 全屏沉浸式主视觉
- 个人简介、经历与能力数据
- 视频创意、详情页设计、首页视觉三个作品分组
- 分类筛选与项目灯箱
- 联系方式
